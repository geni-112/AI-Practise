# Huawei Cloud Big Data Grafana

This directory keeps the reusable observability guidance and the deployable monitoring stack together without mixing their responsibilities.

- [`huawei-cloud-bigdata/`](./huawei-cloud-bigdata/) contains the reusable Huawei Cloud big-data skill and its Grafana/MRS observability reference.
- [`grafana-mrs-observability/`](./grafana-mrs-observability/) contains the deployable Grafana OSS, Prometheus, Loki, Caddy, Huawei exporter, DataArts log collector, FusionInsight/MRS dump exporter, dashboards, and deployment scripts.

Runtime credentials, environment files, private keys, downloaded logs, and deployment-specific resource identifiers must remain outside the repository.
